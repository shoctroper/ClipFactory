# ClipFactory

## Regla de alcance

Todo el trabajo de este proyecto vive dentro de esta carpeta (la raíz de este repositorio). Nada debe salir de aquí: sin escribir, mover ni generar archivos fuera de esta carpeta (incluye scripts, descargas, archivos temporales/scratch, configuración, etc.).

Si una tarea de ClipFactory necesita leer algo de otro repo (por ejemplo `AthenaFramework` para el guion), está permitido leer desde afuera, pero cualquier archivo nuevo o modificado se queda dentro de `ClipFactory/`.

Al empezar una sesión nueva en esta carpeta, lee primero `ARRANQUE.md` — tiene el estado actual y el próximo pendiente. Ver `README.md` para el contexto del proyecto y el estado de la investigación.
